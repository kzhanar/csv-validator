# CSV Validator

## Description

Build and verify a small provider CSV validation application as a BMAD learning project, moving from the canonical specification through traceable stories and tested implementation.

## Outcome

Users can submit a provider CSV file and receive a clear validation report while the project demonstrates the BMAD requirements-to-verification workflow.

## Boundaries

The initiative covers the CSV validation workflow and its Java, Spring Boot, Maven, and JUnit implementation. Persistent storage, non-CSV formats, and production-scale processing are out of scope.
